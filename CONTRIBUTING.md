# Guia de Contribuição - TradBotGems

Obrigado pelo interesse em contribuir com o **TradBotGems**!

## Como Contribuir

1. **Faça um Fork** do repositório.
2. **Crie uma branch** para sua modificação:
   ```bash
   git checkout -b feature/minha-feature
   ```
3. **Escreva código limpo** seguindo as convenções PEP 8 e adicione testes unitários em `tests/` para novas funcionalidades.
4. **Execute os testes** antes de abrir o Pull Request:
   ```bash
   python -m unittest discover -s tests
   ```
5. **Abra um Pull Request** detalhando as alterações implementadas.

## Reportando Bugs

Utilize a aba de [Issues](https://github.com/EliLyn/TradBotGems/issues) e selecione o modelo de **Bug Report**.
